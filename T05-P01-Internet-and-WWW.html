Stage 2 · 10 minutes

Teacher Session – the essential knowledge

1. The Internet and the World Wide Web

The Internet

The Internet is the worldwide infrastructure of interconnected networks and devices that communicate using agreed protocols.

Think: the network infrastructure that carries data.

The World Wide Web (WWW)

The Web is the collection of websites and web pages that people access using the Internet.

Think: one service that uses the Internet.

Cambridge distinction: The Internet is the infrastructure. The World Wide Web is the collection of websites and web pages accessed using that infrastructure. They are related, but they are not the same thing.

2. Uniform Resource Locator (URL)

A URL is a text-based address for a web page or other web resource. It can contain the protocol, the domain name and the web page/file name.

https://www.mescairo.com/secondary/computing.html
ComponentExamplePurpose
Protocolhttps://Identifies the communication protocol used to access the resource.
Domain namewww.mescairo.comHuman-readable name identifying the website's Internet address.
Web page/file name (path)/secondary/computing.htmlIdentifies the requested page or resource on the website.
Exam reminder: A URL is the address of a resource; it is not the resource itself.

3. HTTP and HTTPS

HTTP (Hypertext Transfer Protocol) is a set of rules that allows a browser and a web server to request and transfer web resources. The browser sends a request; the server sends a response.

HTTPS (Hypertext Transfer Protocol Secure) is HTTP communication protected using TLS encryption. It helps protect data while it is travelling between the browser and web server.

HTTP

  • Supports request-and-response communication.
  • Does not provide the TLS encryption of HTTPS.
  • Data is more exposed if intercepted on an untrusted network.

HTTPS

  • Uses HTTP over a TLS-protected connection.
  • Encrypts data in transit.
  • Helps authenticate the server and protect data from unauthorised reading or alteration.
Do not confuse security with trust: HTTPS helps secure the connection. It does not guarantee that the website itself is honest, accurate or free from harmful content.

4. Web browsers – purpose and functions

The main purpose of a web browser is to render HTML (Hypertext Markup Language) and display web pages. A browser also provides tools to help users access and manage web content.

Browser functionWhat it does
Bookmarks / favouritesSaves links to pages so users can return to them quickly.
HistoryRecords pages previously visited.
Multiple tabsAllows several web pages to be open in one browser window.
CookiesStores small pieces of website-related data on the user's device.
Navigation toolsIncludes controls such as Back, Forward, Refresh and Home.
Address barAllows the user to enter a URL and often displays the current URL.

5. How a web page is located, retrieved and displayed

When a user enters a URL, several components work together:

  1. Browser: reads the URL and begins the request.
  2. DNS (Domain Name System): looks up the domain name and returns the corresponding IP address.
  3. IP address: identifies the destination server/device on the network so data can be routed to it.
  4. Web server: receives the browser's request and sends the requested resource in a response.
  5. HTML: the browser receives HTML from the server, interprets it and renders the page for display.

Be precise: DNS translates a domain name into an IP address. The IP address is used to direct network communication to the server. The browser requests the page; the web server responds; the browser renders the HTML.

6. Cookies – session and persistent

A cookie is a small piece of data stored by a website in the user's browser. Cookies help a website remember information between requests or visits.

Session cookie

Usually exists only for the current browsing session and is normally removed when the browser session ends.

Example: remembering items in a shopping cart while the user moves between pages during one visit.

Persistent cookie

Has an expiry time and can remain stored after the browser is closed, until it expires or is deleted.

Example: remembering a language preference for a later visit.

Uses of cookies required by the syllabus

  • Saving personal details.
  • Tracking user preferences.
  • Holding items in an online shopping cart.
  • Storing login details or a login/session identifier so a user can remain signed in.
Privacy reminder: Cookies can support useful functions, but they can also be used to track browsing behaviour. Websites should handle personal information securely; passwords should not be stored as plain text in cookies.

Common mistakes to avoid

  • Do not write that the Internet and WWW are the same. The Internet is the infrastructure; the Web is a collection of websites and pages accessed using it.
  • Do not confuse a URL with a domain name. The domain is only one component of a URL.
  • Do not say HTTPS makes every website trustworthy. It encrypts the connection and helps authenticate the server.
  • Do not confuse DNS with a web server. DNS finds the IP address; the web server provides the requested web resource.
  • Do not confuse session cookies with persistent cookies. Their difference concerns how long they remain stored.
