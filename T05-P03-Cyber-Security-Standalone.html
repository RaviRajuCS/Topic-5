1. Cyber security threats

A cyber security threat is a possible danger to computer systems, networks or data. Attackers may aim to steal information, gain unauthorised access, disrupt services, damage files or make money.

Brute-force attack

An attacker repeatedly tries many password or key combinations until the correct one is found. Aim: gain unauthorised access to an account or system.

Data interception

Data is captured while it is being transmitted across a network, for example by monitoring an insecure connection. Aim: read or steal sensitive information.

Distributed denial of service (DDoS)

Many devices send huge amounts of traffic or requests to a target server at the same time. The server becomes overloaded and legitimate users cannot access the service. Aim: disrupt availability.

Hacking

Someone gains access to a computer system or network without permission, often by exploiting a weakness. Aim: view, change, steal or destroy data, or take control of resources.

Pharming

A user is redirected to a fraudulent website, often through manipulation of DNS settings or a device's hosts file, even when they try to visit the correct address. Aim: steal login or financial details.

Phishing

A fraudulent email, message or website pretends to come from a trusted source and tricks a user into revealing information or clicking a harmful link. Aim: steal credentials, personal data or money.

Social engineering

An attacker manipulates a person into revealing confidential information or performing an unsafe action, using trust, urgency, fear or authority. Aim: bypass security by exploiting human behaviour.

Malware: malicious software

Malware is software designed to harm a device, disrupt its operation, spy on users or gain unauthorised access.

TypeProcess / behaviourPossible aim or effect
VirusAttaches itself to a legitimate file or program and runs when the infected host is executed. It can copy itself by infecting other files.Corrupt, modify or delete data; disrupt a system.
WormSelf-replicates and spreads between devices, often across networks, without needing to attach to a host file.Spread rapidly, consume resources or deliver a harmful payload.
Trojan horseDisguises itself as useful or legitimate software. When installed or run, it performs hidden malicious actions.Open a back door, steal data or install other malware.

Do not confuse: A virus needs a host file or program; a worm can spread independently. A Trojan horse relies on disguise and does not self-replicate in the same way.

2. Solutions that help keep data safe

Access levels

Users are given permissions appropriate to their roles. For example, a student may read a file but not edit or delete it. This limits unauthorised access and damage.

Anti-malware

Anti-virus software detects, blocks, quarantines or removes malicious software. Anti-spyware focuses on detecting and removing spyware. Definitions and detection engines should be kept current.

Authentication

Checks that a user is who they claim to be. Methods include username and password, biometrics such as fingerprint or face recognition, and two-step verification using a second check.

Automated software updates

Installs security patches when available, reducing the time systems remain vulnerable to known weaknesses.

Check spelling and tone

Unexpected spelling errors, unusual wording, urgent demands or threatening language can indicate a fraudulent message. Verify the sender independently.

Check the URL attached to a link

Inspect the actual domain carefully before opening a link. Look for misspellings, extra words or misleading domain names; do not rely only on the displayed link text.

Firewalls

Monitor and filter incoming and outgoing network traffic according to security rules. They can block unauthorised connections, but do not stop every type of attack.

Privacy settings

Control who can see personal information, posts, location and account details. Restricting visibility reduces unnecessary exposure.

Proxy servers

Act as an intermediary between a user's device and the internet. They can filter requests, hide internal IP addresses and enforce access policies; they are not a complete security solution.

SSL security protocol

SSL is the syllabus term for a protocol used to secure communication by encrypting data between a client and server and helping authenticate the server. Modern websites generally use TLS, the successor to SSL.
